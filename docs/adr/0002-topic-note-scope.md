# 笔记范围由读取专题选择来源子树

状态：accepted（2026-11-15，第七至九轮讨论确认）。

分散的向上汇集／向下共享开关难以表达具体选择，改为每个专题从完整真实专题树选择来源，允许跨分支。选中父节点持续包含子树，明确排除覆盖继承，新节点按最近祖先规则决定，展示和助理使用保持一致。

此设计允许用户主动引入兄弟方向，但不通过专题关系或其他专题的汇集结果间接扩大范围；按原始归属读取、按 ID 去重，不复制笔记，不修改文献关系。它替代早期仅父子共享规则，后续实现不能混用两套语义。

实现对应阶段四的 topic_note_scope 与 Notebooks 服务；普通关系通过阶段五 Relations 服务维护，不参与范围继承。当前状态见 [PLAN](../../PLAN.md)。
