# 研究记忆自动维护，正式资料统一预览采纳

状态：accepted（2026-11-15，计划讨论第一轮确认）。

研究助理需要自动积累连续讨论的背景，正式笔记与关系则需要用户掌握修改边界。因此研究事件和研究记忆自动维护，无须逐次批准，用户可查看、纠正与删除；正式专题、笔记、元数据及关系统一先生成修改方案，即使用户明确要求创建，也需预览后采纳。

此选择牺牲纯新增操作的一次点击便利，换取一致的版本校验、整组采纳和撤回语义。普通回答不需确认；自动记忆中的推断保持未确认状态，不提升为用户决定或原文事实。未来简化新增操作须重新讨论权限边界。

实现对应研究记忆服务与阶段五 collaboration 方案服务；当前阶段与验证状态见 [PLAN](../../PLAN.md)。正式资料采纳与研究记忆维护继续分离。
