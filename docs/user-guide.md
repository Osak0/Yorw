# 知栖 Yorw 使用指南

适用：当前 v0.4.0 开发工作树（应用版本仍为 0.3.0，schema 28），此前四阶段及后续阅读／批量元数据与问答上下文改进已 review 通过，状态与验证边界见 [PLAN](../PLAN.md)。远端 Release 状态本轮未核验。

## 打开与配置

在完整分发目录中运行 `Yorw.exe`，或使用随包安装器。直接运行时需保留整个目录。程序已包含所需运行时；当前包未签名，尚未在独立干净 Windows 上验收。

退出旧版后再打开新版本。已有资料位于 House 显示的数据位置，升级会先备份数据库再应用迁移。0.2.0 的数据库版本高于 0.1.0，升级后的库需使用新版程序；自动迁移备份不是包含 PDF 等文件的完整工作区备份。

在 House 分别填写聊天模型与检索模型的地址、型号和密钥，保存后测试连接。密钥在应用中安全保存，不要发送到聊天或反馈中。数据默认保存在本地，云端模型会接收完成当前任务所需的相关文本。

House 的“语义检索”默认开启。关闭后，搜索和材料查找使用本地文字匹配；问答和草稿生成仍使用聊天模型。没有模型配置时仍能阅读、编辑和导出。

## 工作标签

顶部模块导航下是统一工作标签栏。点击 Storage / Garden / House 进入模块首页并保留已打开标签；点击标签回到对应页面。打开同一文献、专题或工具会激活已有标签，不重复创建；编辑元数据、新建专题和专题管理也是独立工作标签。标签可以关闭，也可以“关闭其他”；存在未保存元数据、笔记、专题正文、新建/管理表单或 AI 草稿时，会询问保存/创建并关闭、放弃并关闭或取消，保存失败会保持标签打开。

程序支持恢复标签顺序、激活项、模块首页、侧栏模式、专题目录的收起状态、Garden 层级/路径视图和展开项；旧布局缺少新字段时使用默认值。布局只保存页面描述与界面偏好；未保存正文、新建/管理表单、聊天/检索输入、页面缩放和任务结果不会写入布局，也不承诺崩溃恢复。

## Storage：文献目录、阅读、搜索和问答

文献库首页左侧是可收起的文献目录，列出文献标题和文件名；点击目录项或“打开阅读”都会在新标签页打开文献。首页中右侧保留文献列表，可在“搜索文献”中按标题、文件名、作者、年份、标签或总结过滤；搜索只在本地进行，不调用模型。点击“收起目录”/“展开目录”可调整列表宽度，状态会随布局恢复。

点击“导入文献”可一次选择多个 PDF、DOCX、DOC、Markdown 或 TXT；程序逐个保存受管原文、按摘要去重并解析，逐文件显示成功、已存在或失败原因。单个文件失败不会中止整批。作者和年份等未知信息可留空；原始文件不会因为在知栖中移除文献而被删除。解析状态分为“解析成功、部分解析、暂不支持、解析失败”；失败时文件仍保留，可配置组件或选择处理器后重新解析。

导入成功后可选择“整理资料”，它会在新的“编辑元数据”标签中打开元数据编辑，填写标题、作者、年份、标签、总结，并管理关联材料和专题；也可以跳过直接“打开阅读”。打开元数据不会发送自动总结请求。重复导入同一 PDF 会复用现有记录，仍可打开或整理其元数据。

点击“打开阅读”：PDF 使用原件，可切换“单页展示”或“连续展示”，页码随当前阅读页更新；“缩略图”和“目录”打开可收起的左栏，目录读取 PDF 自带书签，无书签时可用缩略图或页码。“专注阅读”扩大至应用窗口，Esc 退出；上一页／下一页和输入页码可直接定位，缩放和物理页位置继续保留；DOCX 默认使用无需外部组件的“原件基础预览”，直接读取保存的 DOCX 文件，显示正文、基本样式、表格和常见内嵌图片，不使用检索内容块重建整篇页面。复杂分页、页眉页脚、脚注及特殊图片格式不保证还原，可主动选择“版式预览（可选）”或用系统应用打开。左侧原件只读，笔记和资料仍可编辑。

Markdown 默认安全阅读视图，可切换原始文本；TXT 保留原文件换行和空白。Markdown 不加载 HTML、远程图片或原目录附件。旧二进制 DOC 的完整预览与文字抽取需要可选 LibreOffice；没有该组件时，可管理文件/资料/笔记，查看已有依据，或另存为 DOCX 后使用内置处理，不会声称旧 DOC 已具备完整内置解析能力。

检索、问答、笔记与专题来源统一提供“查看依据”：首先直接展示原文摘录及章节信息；若能在 DOCX 基础预览或 TXT/Markdown 原文中唯一匹配，再标记对应内容。无法预览、转换失败或无法唯一匹配时，仍显示依据，不让用户等待一个不可用的跳转接口。

Word 的可选版式预览通过用户安装并授权的 LibreOffice 转 PDF，转换过程与基础阅读、RAG 解析独立。未配置时，点击会提示所需组件，基础阅读不消失。仅在确认匹配时定位转换页，跨页依据可切换匹配页；转换页号不会写回原始来源。转换字体和排版可能与 Word 不同。

House 首页只保留“文献解析与预览、聊天模型、检索、数据与导出”入口，点击打开设置标签；重复打开会激活已有标签。切换标签保留草稿，关闭有修改的设置标签会提示保存或放弃。密钥草稿只在内存中保留。首次配置或旧配置升级时，在解析设置中选择并授权 Docling/LibreOffice，再保存；main 保存组件文件指纹，重启后仅恢复文件未变化的授权，组件更新后需重新授权；也可清除不使用的组件路径。启动参数由程序固定，普通状态读取不会启动组件。高级选项中设置超时和 OCR。


阅读页右侧的笔记、检索、问答默认在侧栏切换，也可以点击“展开为标签”变成标有所属文献标题的独立标签；“返回阅读侧栏”回到阅读页侧栏。两种宿主复用同一份输入、结果和编辑状态。点击引用或“查看原文”会回到对应文献的阅读标签并跳到物理页；目标阅读标签不存在时会创建，不会替换其他文献。

**搜索：** 打开“检索”，输入关键词或问题，点击“搜索”。后台自动准备和复用索引，结果只查找当前文献。每条结果显示短原文摘录和页码；点击标题或“查看原文”跳到相应页。服务暂不可用时会展示可用的初步匹配结果。无匹配时可调整问法。清空输入（包括仅空格）后按 Enter 会清空上次结果展示，不发请求、不删除历史；再次选择历史或执行新检索可恢复展示。结果筛选暂不可用的说明不再显示，其他错误仍保留。

**问答：** 打开“问答”，上方是对话记录，下方是固定输入框。输入问题后按 Enter 发送，Shift+Enter 换行；输入法组合输入期间不会误发送。生成时输入框旁显示“停止”；向上阅读旧消息时显示“回到最新”。可以继续追问；近期对话用于理解指代，答案仍须寻找当前文献的原文依据。点击引用可回到对应页，唯一匹配的 PDF 摘录会以黄色高亮显示，点击“保存到笔记”保存独立内容及引用。证据不足时不能把模型猜测当作论文结论。

**笔记：** 使用 Markdown 编辑，点击“保存笔记”或 Ctrl+S。切换文献或标签时会话内的编辑保留，关闭前请保存；未保存编辑尚无崩溃恢复能力。

**文献管理与元数据：** 文献列表只保留“打开阅读”和“管理文献”。管理按钮用颜色表示展开，在下方依次显示编辑元数据、笔记、检索、问答、解析、删除文献。前四项打开对应独立标签；解析进一步展开处理器选择、重新解析或停止。

- 元数据页按标题、作者、年份、关键词／标签、总结、相关文献、所属专题排列。阅读工具栏和目录右键的“编辑元数据”进入同一标签；旧资料标签恢复时映射到元数据并去重。
- 元数据草稿按文献在会话内保留。关闭修改过的标签可保存、放弃或取消，保存失败保持标签；退出有未保存保护，不承诺崩溃恢复。删除文献前需处理未保存笔记和元数据，确认后关闭该文献所有工作标签。
- 元数据上方“AI 辅助文献整理”打开独立结果标签，旧生成历史、隐藏／恢复和原有显式生成／逐字段采纳仍可使用。无结果且无任务时首次进入自动生成，失败／取消后显式重试。七类字段下方分别提供添加／替换，替换前确认；标题／年份的添加仅填空，已有值时禁用。已有元数据草稿需先保存或放弃。相关文献／专题仅推荐本地已有项，替换关系会解除现有关联；未知事实留空。
- 相关文献由你查找并关联，可填说明，关系双向显示；所属专题从已有专题选择。解除关联不删除文献、专题、笔记或原文，也不自动扩大 AI 材料范围。相同标签仅辅助查找。
- 笔记、检索、问答与阅读侧栏使用同一份状态。独立检索标签顶部固定搜索，点击“检索历史”展开／收起左栏，点击历史在右侧看当时状态与结果；查看不会调用模型，重新检索才新建任务。阅读侧栏不显示检索历史，专注当前问题。问答记录搜索位于独立标签顶栏“返回阅读侧栏”左侧，阅读侧栏保留精简输入；搜索问题与回答正文，点击结果定位后淡色背景约1.8秒自动消失。

## Garden：专题、笔记与范围

首页上方是研究助理入口，下方保留专题树、层级／路径视图、搜索和新建。点击专题打开概览，依次为笔记、关联材料、关联专题；每类显示前 5 项及总数，详细操作点击“查看全部”。共享笔记默认收起，展开后可看到原始归属。概览不嵌入全文编辑器。

在笔记模块点击“新建笔记”，填写标题后打开独立详情。每个专题可有多份笔记，详情提供编辑、预览、保存、AI 优化、修订历史、重命名和删除。Ctrl+S 保存新修订；版本冲突保留草稿，比较最新版本后再决定。共享入口编辑的是同一份原笔记，不会复制到当前专题。删除笔记影响所有共享入口，历史修订保留。

文献笔记仍唯一归属于文献，从专题点击后打开该文献的笔记工具，阅读侧栏与详情共用状态。保存后可查看“笔记修订”，复制历史正文为编辑草稿；正式保存前不会改变当前笔记。升级前未保存的逐版本正文无法补造，历史从升级时的当前版本开始。AI 优化必须先保存；候选保留为生成记录，追加／替换需手动采纳。其他入口已修改笔记时拒绝覆盖，输入保留。

“笔记范围”展示完整专题树，选项是实际专题名称。勾选某个专题默认包含其子树，可展开逐项排除；父项以部分选择状态提示。新建子专题继承最近显式祖先规则，移动后按新祖先重算，节点自身明确选择／排除仍保留。笔记展示与 AI 使用同步采用这一份范围，不另选“全工作区”。例如 A 读取 B，B 又读取 C，不会因此将 C 的笔记转发给 A；只有 A 自己选中 C 才读取。文献笔记随文献直接关联出现在相应范围，按原笔记 ID 去重。

范围草稿在本次会话跨标签保留，关闭可保存、放弃或取消；保存过程中继续勾选不会被旧响应覆盖。未保存范围不用于生成。范围或来源变化会阻止旧任务继续使用过时材料，不自动重试付费请求。

AI 优化打开独立标签，填写要求后生成可编辑建议。材料范围沿用所属专题的已保存笔记范围；文献笔记优化使用其所属文献和笔记记录。用户笔记／旧写作快照只证明写过什么，不是论文事实。完成后查看来源与比较，再“追加到正文”“替换正文”或“忽略草稿”；生成本身不修改正式内容。回退复制历史为新修订，不改写旧修订。未保存编辑、材料或版本变化需要先核对，不能盲目采纳。工具页可返回笔记，应用重启不会自动重发调用。

专题管理仍合并名称与父级编辑，移动前会显示笔记范围受影响的专题。删除拥有专题笔记的目录时，必须选择迁移笔记至其他专题，或明确删除这些笔记；共享显示的其他笔记不随目录删除，文献和阅读笔记保留。子专题按已有规则提升到上一级。“关联专题”当前展示和管理父子目录，普通专题关系将在后续统一关系阶段接入；范围勾选不等于建立专题关系。

旧专题入口现在打开概览，旧正文、修订和 AI 草稿通过原身份继续访问。迁移不会把未采纳草稿变成正式正文，真正空专题不制造空笔记。旧正文笔记单独删除后，当前正文留空，历史保留；不会从专题导出再显示已删除的正文。

## House：内置能力与可选解析组件

无需另装外部解析组件即可使用 PDF 文字抽取、DOCX/Markdown/TXT 解析、原件基础阅读、本地关键词检索、资料和笔记。问答需要另行配置聊天模型服务；这与外部文献解析组件是两类设置。语义检索未配置时可使用本地文字匹配。

| 能力 | 默认内置 | 可选补充 |
| --- | --- | --- |
| PDF 文字与原件阅读 | pypdf + PDF.js | Docling 增强解析/OCR |
| DOCX 文字、表格与基础原件预览 | 内置 OOXML 处理，不需要 Word/LibreOffice | LibreOffice 转换版式预览；Docling 手动增强解析 |
| Markdown/TXT | 内置解析与原文件阅读 | Markdown 可手动选择 Docling；TXT 不依赖它 |
| 旧 DOC 二进制格式 | 保存原件、管理资料/笔记、显示已有依据 | LibreOffice 提供文字转换与版式预览；也可自行另存为 DOCX |
| 扫描 PDF 文字识别 | 内置仍可阅读图片原件，但不识别图片文字 | 用户配置 Docling 与 OCR 环境 |

导入始终使用内置处理，不因旧的“增强优先”设置而改变。想使用可选增强能力时，在文献列表的处理器选项中主动选择“增强解析（可选 Docling）”，再点击“重新解析”。未配置时提示安装/授权步骤，已有正文和基础阅读不受影响；解析失败保留上一可用版本。重试入口默认使用内置解析。

### 可选：LibreOffice

1. 从 [LibreOffice 官方下载页](https://www.libreoffice.org/download/download-libreoffice/)自行下载安装 Windows 版本；已有 Word 并不等于已安装 LibreOffice。
2. House → 文献解析与预览 → “选择并授权 LibreOffice”，选择实际 `soffice.exe`，通常为 `C:\Program Files\LibreOffice\program\soffice.exe`，在原生确认框核对路径后允许。
3. 保存配置，再“检测组件能力”。旧 DOC 可重新使用内置转换接口处理；在 Word 阅读页面主动点击“版式预览（可选）”才生成 PDF。
4. 清除路径不会删除组件或原件；DOCX 基础阅读仍可使用。程序更新后，文件指纹改变，需要重新选择授权。

### 可选：Docling / OCR

Docling 在用户自己的独立 Python 工具环境中安装，不放入 Yorw 的 `.venv`。本机验证基线为 Docling 2.144.0 / Python 3.12；安装方式和 OCR 组件见 [官方安装说明](https://docling-project.github.io/docling/getting_started/installation/)与 [OCR 说明](https://docling-project.github.io/docling/concepts/OCR/)。以下命令由用户自行执行；Yorw 不执行安装命令：

```powershell
# 需要已安装 uv；只需基础增强时可省略 OCR extras。
uv tool install --python 3.12 "docling[rapidocr,onnxruntime]==2.144.0"
(Get-Command docling).Source
```

1. 在 House 选择并授权实际 `docling.exe`，通常位于 `%USERPROFILE%\.local\bin\docling.exe`；以安装输出或上面查询到的路径为准。不填写任意启动参数。
2. 保存并检测，确认组件可用，再在具体文献上选择增强解析。PDF/DOCX/Markdown 不需要先使用 Docling 才能导入或阅读。
3. 扫描 PDF 的 OCR 是可选任务：高级设置中启用 OCR，选择已在 Docling 环境准备好的引擎；本机样例使用 RapidOCR + 整页 OCR。不同引擎可能还需要其独立依赖和模型权重，缺失时补齐该工具环境，不影响 Yorw 内置能力。
4. 首次模型下载、网络、CPU/内存成本由用户的 Docling 环境承担。Yorw 不自动切换第三方镜像；网络受限时可自行准备权重或配置工具环境。真实论文的识别质量仍需人工核查。

普通状态查询不启动程序；显式检测和用户主动发起的处理才使用已授权组件。main 保存程序指纹，重启时恢复未变化的授权。外部解析器不提供额外编辑权限；所有依据仍使用版本化来源记录。

## House：内容导出

选择已保存笔记和 Wiki 当前修订，点击“创建快照并导出 ZIP”，通过系统对话框保存。取消后可以再次保存同一快照；修改正文后需要创建新快照。

ZIP 中的 Markdown 保持已保存正文原样，来源清单记录材料类型、原始证据、版本及导出时来源状态。追加和替换产生的来源关系同样会导出。

内容导出不包含 PDF、密钥、模型配置、完整对话、全部修订历史或未保存编辑，也不提供完整恢复导入。卸载程序配置为保留应用数据。

## AI 辅助文献整理

从编辑元数据上方点击“AI 辅助文献整理”进入独立标签。无记录且无任务时首次进入会生成一次；已有结果直接复用，失败／取消后需显式重试。请求会向当前聊天模型发送已解析原文及当前元数据，可能产生费用。无需配置外部解析器或向量服务，基础阅读不受影响。

固定显示标题、作者、年份、关键词／标签、总结、相关文献、所属专题七栏，逐栏对比当前值和建议。缺少信息保留栏目并禁用采纳；不再单列研究方法、概述或局限。每栏有添加／替换，无勾选框。标题行右侧另有“全部添加”和“全部替换”，一次采纳全部可用建议；全部添加跳过已有标题／年份，空建议不改变原值，全部替换统一确认后执行。所有参与字段和关系一起校验、一起保存，冲突时整体不写入。添加标题／年份仅填空；作者和标签去重追加，总结保留当前内容追加，相关文献／专题追加已有本地项。替换前核对确认，替换关系会解除当前关联。生成本身不改变正式元数据；有未保存元数据草稿时先保存或放弃。

每次成功生成独立保存，生成记录可切换、隐藏及恢复，查看已有记录不重新请求模型。历史模型名称未记录时如实显示；旧记录的概述兼容为总结，旧全空记录需显式重新生成，不能从它还原模型原始响应。原文过期的记录只能查阅，不能采纳。并发更新或候选变化时拒绝采纳，核对后重试。

相关文献和专题依据内容从已有本地库推荐，不联网、不自动新建专题；采纳关联不会扩大问答或专题草稿材料范围。元数据页仍可手动维护关系。

每篇最多 32 个文字批次及一次汇总，超预算明确失败。失败详情展示错误码、阶段及相关字段，不记录密钥或完整模型响应；全空或格式错误最多修正一次，非法来源拒绝保存。失败保留既有人工资料和旧生成结果，不能保证远端模型每次成功。取消不能撤销已发出的请求；重启不自动重发中断／失败任务。正文可上下滚动，底部按钮和来源可达。

House → 文献解析与预览 → 导入后自动整理，默认关闭。开启即授权发送后续新导入文献的已解析文字，现有文献不会批量补发。关闭会取消未完成的自动任务。

House → 检索 → 元数据辅助检索（试用），默认关闭。启用后正式标题、标签、总结及当前 AI 资料辅助查找，输出仍引用原文；真实论文和模型质量待评估，需核对依据。

## 文献文件夹与系统操作

文献目录从根目录开始，显示当前目录直属文件夹和文件；没有归入文件夹的文献位于根目录。单击文件夹名称展开或收起子目录与文献，双击名称进入文件夹（键盘 Enter 也可进入），点击“上一级”返回父目录，路径栏标明当前位置。右侧搜索仅筛选当前目录直属文献。目录栏保留唯一的“导入文献”按钮，新导入归入当前目录，重复导入保持原归属。

目录行仅显示文件名称，长名称省略但悬停可查看全名。右键点击文件或文件夹打开分组菜单，也可聚焦后使用 Shift+F10 或菜单键。菜单支持方向键、Home/End、Enter、Esc，点击外部关闭。文献可阅读、编辑元数据、编辑标题、移动、查看/复制原件位置、系统打开及移除；文件夹可进入、新建子文件夹、改名/移动和删除。空白处右键可新建文件夹或导入。

移动文献通过右键“移动到…”选择完整目标路径，根目录也是目标。删除非空目录前确认影响，子目录和文献提升至父级；同级重名时阻止删除并保留数据。目录组织与 Garden 关系独立，移动不重新解析原件。复选框和行内更多按钮已移除。

拖动文献目录与右侧列表之间的分隔条调整宽度；聚焦分隔条后可用左右方向键调整，Home/End 选择宽度边界。宽度和当前目录在本机保留；旧“全部文献/未分类”布局自动回到根目录。

“原件存储位置”是 Yorw 保存的副本位置；导入时外部文件的旧路径没有被记录。系统打开使用临时副本以保护受管原件；资源管理器定位与绝对路径对应受管原件，勿直接修改该文件。若需修改，请另存后导入。缺失或不可访问的原件会提示失败。


## Garden 专题右键操作

在首页层级树、路径列表或正文左侧目录右键点击专题名称，可打开专题、新建子专题、进入专题管理（名称与父级）、查看修订历史或删除专题。上方工具栏继续负责整体操作。键盘聚焦名称后按菜单键或 Shift+F10 打开，方向键选择，Enter 执行，Escape 关闭。

删除前会显示确认：只删除选中的专题，直接子专题移到它的父级；删除根专题时，其直接子专题移到根目录。文献原件不删除，目标专题的文献关联解除。已保存修订保留在数据库中，旧来源快照保留但此专题不再可用；当前没有恢复已删除专题的界面入口。

若有未保存正文、专题管理或 AI 比较编辑，请先保存，或关闭相应标签并选择放弃，再删除。目录版本冲突时取消对话框、刷新目录并核对后重试。成功后该专题的正文、管理和工具标签关闭，其他专题继续保留。

## 当前文献的 History.md

独立问答页顶栏和阅读问答侧栏提供“查看 History.md”，可查看当前文献的历史总结、近期问答、压缩轮数及预算，点击刷新读取最新状态。独立文献工具页的导航仅保留“返回阅读侧栏”，不再重复显示“打开阅读”；编辑元数据的关闭编辑仍可使用。

原始对话按文献保存，不会混入另一篇文献。近期最多三轮作为上下文，每新增六轮旧记录或历史超预算时压缩总结；模型压缩可能增加一次请求，失败时本地压缩，不影响已生成的回答。历史摘要用于理解“继续”“请回答完全”等追问，不是论文事实，回答仍重新寻找当前原文。未完成回答在历史中标明，旧引用编号不沿用。

History.md 同步导出在 House 显示的工作区内 `chat-history/<文献UUID>/History.md`；界面和提示词以数据库为准，直接修改导出文件不会改变系统上下文。历史注入限制为 4096 token 的保守估计；整个问题、上下文和原文输入也有上限。重新解析切换原文版本后不再使用旧总结，原始记录仍保留。来源确实失效时仍会停止生成，不将旧回答伪装为当前证据。

依据跳转在目标页文字层准备好后，将唯一匹配的高亮段落移入阅读视口；每次点击只定位一次，之后可自由滚动。点击高亮之外或按 Esc 可清除高亮；再次点击来源可重新定位。无法唯一匹配或没有可用文字层时保留页级定位，不猜测高亮位置。

## House：研究助理模型（阶段一）

进入“研究助理模型”，可新增、选择、编辑或删除多份 DeepSeek／Kimi／GLM／Qwen／自定义兼容服务配置。通用地址可预填，模型名称需填写；地域和专用套餐请使用服务商指定地址。密钥留空保留，勾选清除才删除；更换地址需要重输或清除，保存后密钥不回显。旧聊天配置升级后作为独立副本出现，不修改原聊天设置。

保存后分别点击“检测聊天”和“检测工具闭环”。后者会向所选模型发送自编写验证材料，执行检索、读取和引用流程，可能产生费用，不读取真实论文。检测中可停止，结果分别显示时间和通过状态；修改配置后需重新检测。模型未通过工具检测不代表普通聊天也不可用。研究及记忆总结可分别选择默认配置，记忆选“沿用研究模型”时随研究默认；这些选择用于研究助理和记忆维护，当前文献问答、整理和优化继续使用“聊天模型”页的设置。未保存表单在关闭／切换配置时受草稿保护。

## Garden：研究助理与研究记忆

首页顶部输入研究问题，选择整个工作区或某个专题后发送，才创建会话并打开独立助理标签。空白输入不创建记录。笔记详情工具栏的“研究助理”打开带当前专题范围的新会话入口。先在 House“研究助理模型”保存配置、完成工具检测并设置默认模型；会话内也可选择其他已配置模型。

左侧历史栏可收起，点击历史恢复旧会话；“新会话”回到空白入口。切换工作标签保留当前对话，关闭后重开不自动恢复或发送旧问题。可归档、恢复或删除会话；删除不影响正式笔记及文献。跨会话背景由研究记忆提供，历史会话仍由你主动选择，不会自动跳转。

助理可多次检索并读取当前原文、阅读笔记和旧专题正文；正文引用按钮可进入原文定位高亮，阅读笔记进入该文献笔记，专题笔记来源打开独立笔记详情。未核对的笔记仅视为用户观点，不代替论文证据。专题范围采用该专题保存的笔记范围；默认本专题及后代，允许明确选择其他分支；普通关联不自动扩大范围。

顶部可主动修改范围，会记录变更并停止旧任务，旧消息仍保留显示，后续上下文重新核对；来源变化或移出范围后禁止跳转。生成期间可停止，失败／中断保留已有正文，点击重新回答才发起新请求。应用重启不会自动继续收费任务；整个工作区前台 AI 忙碌时新请求不排队，输入保留，结束后再发送。上滑阅读暂停跟随，可点击“回到最新”。当前只读工具不会创建、修改笔记或建立关系。

助理顶部点击“研究记忆”，选择全局或专题。用户研究指引可写目标、偏好和约束；全局自动内容只维护方向索引，专题背景用于理解研究问题、进展和待验证想法。背景不是论文证据，事实仍需读取当前原文。自动记录不要求你逐条批准，也不会因此直接修改正式笔记或专题。

“纠正”打开正文编辑框，保存后优先使用新说法；“忘记”排除此条及其依据事件，影响工作区内后续召回和压缩，但不删除原对话、论文和正式笔记。在“活动记录”可查看片段并忘记具体活动；“修订与遗忘”可恢复用户指引版本或明确重新引入记录。恢复指引不会自动恢复已忘记背景。来源移出范围或版本改变时，依赖该来源的自动背景先排除。

“自动维护设置”控制暂停、讨论／活动阈值、最短间隔、每日模型摘要次数和单次输入预算。默认 6 轮／20 条触发，模型摘要每专题至少间隔 10 分钟，全工作区每天最多 20 次；使用 House 记忆模型或研究默认。无模型、额度或调用失败时保留原记录并做本地整理，正常提问不因此失败。后台维护会使用相关记录并可能产生模型费用；暂停后不再安排，在途结果不写入。

指引及用户纠正过长时允许保存，但发送问题会提示缩短，不会悄悄截断。界面显示保守 token 估计，实际费用以模型服务为准。自动背景更新不打断回答；你纠正或忘记旧背景时，相关旧任务会停止，重新发送使用新背景。

“查看 Research.md／Log.md”显示当前背景或最近活动，“导出 Markdown”写到工作区 research 目录；专题文件在 topics/<专题UUID>/。完整问答保留于原会话，Log 导出仅包含活动摘要及对象引用。外部编辑这些文件不会自动改变助理记忆。
