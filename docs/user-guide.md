# 知栖 Yorw 使用指南

适用：阶段二开发分支 feature/document-enrichment-rag（应用版本仍为 0.2.0）· schema 20 · 2026-10-29。阶段一已合并 main，阶段二等待 review，不代表应用已发布。

## 打开与配置

在完整分发目录中运行 `Yorw.exe`，或使用随包安装器。直接运行时需保留整个目录。程序已包含所需运行时；当前包未签名，尚未在独立干净 Windows 上验收。

退出旧版后再打开新版本。已有资料位于 House 显示的数据位置，升级会先备份数据库再应用迁移。0.2.0 的数据库版本高于 0.1.0，升级后的库需使用新版程序；自动迁移备份不是包含 PDF 等文件的完整工作区备份。

在 House 分别填写聊天模型与检索模型的地址、型号和密钥，保存后测试连接。密钥在应用中安全保存，不要发送到聊天或反馈中。数据默认保存在本地，云端模型会接收完成当前任务所需的相关文本。

House 的“语义检索”默认开启。关闭后，搜索和材料查找使用本地文字匹配；问答和草稿生成仍使用聊天模型。没有模型配置时仍能阅读、编辑和导出。

## 工作标签

顶部模块导航下是统一工作标签栏。点击 Storage / Garden / House 进入模块首页并保留已打开标签；点击标签回到对应页面。打开同一文献、专题或工具会激活已有标签，不重复创建；整理文献也是独立工作标签。标签可以关闭，也可以“关闭其他”；存在未保存笔记、专题正文或 AI 草稿时，会询问保存并关闭、放弃并关闭或取消，保存失败会保持标签打开。

正常重启会恢复标签顺序、激活项、模块首页、侧栏模式以及专题目录和文献目录的收起状态。布局只保存页面描述与界面偏好；未保存正文、聊天/检索输入、页面缩放和任务结果不会写入布局，也不承诺崩溃恢复。

## Storage：文献目录、阅读、搜索和问答

文献库首页左侧是可收起的文献目录，列出文献标题和文件名；点击目录项或“打开阅读”都会在新标签页打开文献。首页中右侧保留文献列表，可在“搜索文献”中按标题、文件名、作者、年份、标签或总结过滤；搜索只在本地进行，不调用模型。点击“收起目录”/“展开目录”可调整列表宽度，状态会随布局恢复。

点击“导入文献”可一次选择多个 PDF、DOCX、DOC、Markdown 或 TXT；程序逐个保存受管原文、按摘要去重并解析，逐文件显示成功、已存在或失败原因。单个文件失败不会中止整批。作者和年份等未知信息可留空；原始文件不会因为在知栖中移除文献而被删除。解析状态分为“解析成功、部分解析、暂不支持、解析失败”；失败时文件仍保留，可配置组件或选择处理器后重新解析。

导入成功后可选择“整理资料”，它会在新的“整理文献”标签中打开元数据编辑，填写标题、作者、年份、标签、人工总结和可选专题；也可以跳过直接“打开阅读”。整理文献不会发送自动总结请求。重复导入同一 PDF 会复用现有记录，仍可打开或整理其元数据。

点击“打开阅读”：PDF 使用原件，可翻页、缩放并保存物理页位置；DOCX 默认使用无需外部组件的“原件基础预览”，直接读取保存的 DOCX 文件，显示正文、基本样式、表格和常见内嵌图片，不使用检索内容块重建整篇页面。复杂分页、页眉页脚、脚注及特殊图片格式不保证还原，可主动选择“版式预览（可选）”或用系统应用打开。左侧原件只读，笔记和资料仍可编辑。

Markdown 默认安全阅读视图，可切换原始文本；TXT 保留原文件换行和空白。Markdown 不加载 HTML、远程图片或原目录附件。旧二进制 DOC 的完整预览与文字抽取需要可选 LibreOffice；没有该组件时，可管理文件/资料/笔记，查看已有依据，或另存为 DOCX 后使用内置处理，不会声称旧 DOC 已具备完整内置解析能力。

检索、问答、笔记与专题来源统一提供“查看依据”：首先直接展示原文摘录及章节信息；若能在 DOCX 基础预览或 TXT/Markdown 原文中唯一匹配，再标记对应内容。无法预览、转换失败或无法唯一匹配时，仍显示依据，不让用户等待一个不可用的跳转接口。

Word 的可选版式预览通过用户安装并授权的 LibreOffice 转 PDF，转换过程与基础阅读、RAG 解析独立。未配置时，点击会提示所需组件，基础阅读不消失。仅在确认匹配时定位转换页，跨页依据可切换匹配页；转换页号不会写回原始来源。转换字体和排版可能与 Word 不同。

House 首页只保留“文献解析与预览、聊天模型、检索、数据与导出”入口，点击打开设置标签；重复打开会激活已有标签。切换标签保留草稿，关闭有修改的设置标签会提示保存或放弃。密钥草稿只在内存中保留。首次配置或旧配置升级时，在解析设置中选择并授权 Docling/LibreOffice，再保存；main 保存组件文件指纹，重启后仅恢复文件未变化的授权，组件更新后需重新授权；也可清除不使用的组件路径。启动参数由程序固定，普通状态读取不会启动组件。高级选项中设置超时和 OCR。


阅读页右侧的笔记、检索、问答默认在侧栏切换，也可以点击“展开为标签”变成标有所属文献标题的独立标签；“返回阅读侧栏”回到阅读页侧栏。两种宿主复用同一份输入、结果和编辑状态。点击引用或“查看原文”会回到对应文献的阅读标签并跳到物理页；目标阅读标签不存在时会创建，不会替换其他文献。

**搜索：** 打开“检索”，输入关键词或问题，点击“搜索”。后台自动准备和复用索引，结果只查找当前文献。每条结果显示短原文摘录和页码；点击标题或“查看原文”跳到相应页。服务暂不可用时会展示可用的初步匹配结果。无匹配时可调整问法。

**问答：** 打开“问答”，上方是对话记录，下方是固定输入框。输入问题后按 Enter 发送，Shift+Enter 换行；输入法组合输入期间不会误发送。生成时输入框旁显示“停止”；向上阅读旧消息时显示“回到最新”。可以继续追问；近期对话用于理解指代，答案仍须寻找当前文献的原文依据。点击引用可查看原文，点击“保存到笔记”保存独立内容及引用。证据不足时不能把模型猜测当作论文结论。

**笔记：** 使用 Markdown 编辑，点击“保存笔记”或 Ctrl+S。切换文献或标签时会话内的编辑保留，关闭前请保存；未保存编辑尚无崩溃恢复能力。

**文献资料与关系：** 点击阅读工具栏的“资料”，或文献列表的“文献资料”，打开该文献的独立资料标签。这里汇总标签、人工总结、所属专题、相关文献、相同标签文献、笔记、检索历史和问答历史。

- 点击“编辑元数据”会在新的“整理文献”标签中打开编辑区，填写标签（每行一个，去空、去重）和人工总结；总结会显示“人工编辑”和更新时间，不替代原文证据。未保存的整理内容在当前会话中按文献保留，切换标签不会丢失；关闭标签或退出会丢弃，请先保存。
- “所属专题”可从已有专题中选择并关联，也可解除关联。解除只删除关系，不删除专题、笔记或原文。
- “相关文献”由你手动查找并关联，可填写简短说明；关系双向显示。解除关联不删除任何资料。相关文献不是学术引用，也不会自动扩大 Garden 的 AI 材料范围。
- “相同标签”只帮助查找使用相同标签的其他文献，不会自动建立关系。
- 检索历史保存实际提交的问题、时间、执行状态、摘录和引用。查看历史不调用模型；点“重新检索”才会创建新任务。来源版本变化后，旧结果显示“来源已失效”。可删除单条或清空历史，笔记和问答不会被删除。
- 笔记和问答历史按摘要列出，点击“打开笔记”“打开问答”回到对应工具页继续处理。

## Garden：专题正文、AI 优化与关联材料

Garden 首页是专题目录。点击“收起目录”可获得更宽的正文区，点击“展开目录”恢复；收起状态会在重启后保留。点击“新建”展开紧凑表单，填写名称和父级后创建专题；点击目录中的专题会打开或激活其正文标签。正文页顶部显示标题、父级路径和“名称与父级”折叠入口；工具栏提供编辑/预览、保存、AI 优化和修订历史。

**正文：** 进入专题即可编辑 Markdown，点击“保存”或 Ctrl+S 创建修订；正文上限 20 万字。保存冲突时比较最新修订，选择保留草稿或载入已保存正文，不会静默覆盖。

**AI 优化：** 点击正文工具栏的“AI 优化”，在所属专题的独立标签中选择材料范围并填写生成要求，然后点击“生成草稿”。

- 默认“当前专题及子专题”：使用本专题及后代专题关联的文献、这些文献的笔记和后代专题的已保存 Wiki；当前专题已保存正文只作为编辑背景。不会混入无关专题。
- “全工作区”：显式扩大为所有已保存文献、笔记和其他 Wiki。
- 当前范围没有可用材料时会提示关联材料或切换全工作区，不会静默回退全库。
- 生成后如果专题关系、后代目录或范围材料发生变化，草稿会保留，但会标记范围已变化并阻止直接采纳；请重新生成或核对来源。

生成状态和草稿历史都在该标签内，完成后可编辑结果、预览、查看来源，然后选择：

- **追加到正文**：保留现有正文并添加草稿，自动整理新增引用编号。
- **替换正文**：用编辑后的草稿保存为当前专题的新修订。
- **忽略草稿**：保留生成记录，不修改正文。

生成不会自动覆盖正式正文。正文存在未保存修改时，先保存或载入已保存版本，再处理草稿；正文或材料在生成后发生变化时需要重新生成。专题 A 生成时可以切换并编辑专题 B，后台任务不会因切换标签取消，重新打开可恢复进度和结果。笔记和 Wiki 的观点不会因为被模型引用就成为论文事实。

**修订历史：** 点击正文工具栏的“修订历史”，在所属专题的独立标签中查看修订列表、来源快照和正文比较。回退会创建新修订并保留历史；查看历史不会覆盖当前草稿，正文有未保存修改时不能回退。

**关联材料：** 点击正文工具栏的“关联材料”，在所属专题的独立标签中维护文献。可以搜索并按标题、作者、年份或标签查找已有文献，点击“关联到本专题”建立直接关联。页面分为“直接关联”和“子专题汇集”：后代专题的文献会汇总显示，但不能在本专题直接解除，需要到对应子专题处理。关联文献的笔记按 ID 去重显示，仍归所属文献所有；新增或编辑笔记后重新打开或刷新即可看到最新内容。移动专题后，后代材料按新目录重新计算；解除关联不会删除笔记、PDF 或已有 Wiki 来源快照。

草稿因长度限制中断时会自动续写一次。仍未完成或连接中断时，已有内容保留，可在 AI 优化标签的“草稿历史”中打开并补全；旧版有正文的失败记录也可编辑。原始生成记录和中断状态继续保留。

## House：内置能力与可选解析组件

无需另装外部解析组件即可使用 PDF 文字抽取、DOCX/Markdown/TXT 解析、原件基础阅读、本地关键词检索、资料和笔记。问答需要另行配置聊天模型服务；这与外部文献解析组件是两类设置。语义检索未配置时可使用本地文字匹配。

| 能力 | 默认内置 | 可选补充 |
| --- | --- | --- |
| PDF 文字与原件阅读 | pypdf + PDF.js | Docling 增强解析/OCR |
| DOCX 文字、表格与基础原件预览 | 内置 OOXML 处理，不需要 Word/LibreOffice | LibreOffice 转换版式预览；Docling 手动增强解析 |
| Markdown/TXT | 内置解析与原文件阅读 | Markdown 可手动选择 Docling；TXT 不依赖它 |
| 旧 DOC 二进制格式 | 保存原件、管理资料/笔记、显示已有依据 | LibreOffice 提供文字转换与版式预览；也可自行另存为 DOCX |
| 扫描 PDF 文字识别 | 内置仍可阅读图片原件，但不识别图片文字 | 用户配置 Docling 与 OCR 环境 |

导入始终使用内置处理，不因旧的“增强优先”设置而改变。想使用可选增强能力时，在文献列表的处理器选项中主动选择“增强解析（可选 Docling）”，再点击“重新解析”。未配置时提示安装/授权步骤，已有正文和基础阅读不受影响；解析失败保留上一可用版本。重试入口默认使用内置解析。

### 可选：LibreOffice

1. 从 [LibreOffice 官方下载页](https://www.libreoffice.org/download/download-libreoffice/)自行下载安装 Windows 版本；已有 Word 并不等于已安装 LibreOffice。
2. House → 文献解析与预览 → “选择并授权 LibreOffice”，选择实际 `soffice.exe`，通常为 `C:\Program Files\LibreOffice\program\soffice.exe`，在原生确认框核对路径后允许。
3. 保存配置，再“检测组件能力”。旧 DOC 可重新使用内置转换接口处理；在 Word 阅读页面主动点击“版式预览（可选）”才生成 PDF。
4. 清除路径不会删除组件或原件；DOCX 基础阅读仍可使用。程序更新后，文件指纹改变，需要重新选择授权。

### 可选：Docling / OCR

Docling 在用户自己的独立 Python 工具环境中安装，不放入 Yorw 的 `.venv`。本机验证基线为 Docling 2.144.0 / Python 3.12；安装方式和 OCR 组件见 [官方安装说明](https://docling-project.github.io/docling/getting_started/installation/)与 [OCR 说明](https://docling-project.github.io/docling/concepts/OCR/)。以下命令由用户自行执行；Yorw 不执行安装命令：

```powershell
# 需要已安装 uv；只需基础增强时可省略 OCR extras。
uv tool install --python 3.12 "docling[rapidocr,onnxruntime]==2.144.0"
(Get-Command docling).Source
```

1. 在 House 选择并授权实际 `docling.exe`，通常位于 `%USERPROFILE%\.local\bin\docling.exe`；以安装输出或上面查询到的路径为准。不填写任意启动参数。
2. 保存并检测，确认组件可用，再在具体文献上选择增强解析。PDF/DOCX/Markdown 不需要先使用 Docling 才能导入或阅读。
3. 扫描 PDF 的 OCR 是可选任务：高级设置中启用 OCR，选择已在 Docling 环境准备好的引擎；本机样例使用 RapidOCR + 整页 OCR。不同引擎可能还需要其独立依赖和模型权重，缺失时补齐该工具环境，不影响 Yorw 内置能力。
4. 首次模型下载、网络、CPU/内存成本由用户的 Docling 环境承担。Yorw 不自动切换第三方镜像；网络受限时可自行准备权重或配置工具环境。真实论文的识别质量仍需人工核查。

普通状态查询不启动程序；显式检测和用户主动发起的处理才使用已授权组件。main 保存程序指纹，重启时恢复未变化的授权。外部解析器不提供额外编辑权限；所有依据仍使用版本化来源记录。

## House：内容导出

选择已保存笔记和 Wiki 当前修订，点击“创建快照并导出 ZIP”，通过系统对话框保存。取消后可以再次保存同一快照；修改正文后需要创建新快照。

ZIP 中的 Markdown 保持已保存正文原样，来源清单记录材料类型、原始证据、版本及导出时来源状态。追加和替换产生的来源关系同样会导出。

内容导出不包含 PDF、密钥、模型配置、完整对话、全部修订历史或未保存编辑，也不提供完整恢复导入。卸载程序配置为保留应用数据。

## 异常与反馈

| 现象 | 操作 |
| --- | --- |
| 模型未配置或鉴权失败 | 到 House 保存并测试相应模型配置。 |
| 搜索服务不可用 | 可先查看初步文字匹配；检查 House 配置后再试。 |
| 草稿未完成 | 编辑已有内容并核查来源，或调整要求后重新生成。 |
| 保存冲突 | 当前编辑保留，比较最新版本后再决定。 |
| 关闭标签时提示未保存 | 选择保存并关闭、放弃并关闭或取消；保存失败或冲突会保持标签打开。 |
| 重启后标签或专题缺失 | 恢复会跳过已不存在的页面并提示；布局损坏时回到 Storage 首页。 |
| 本地服务退出 | 关闭并重新打开；已保存内容和部分生成结果保留，中断任务不会自动重发。 |
| PDF 加密、无文字或损坏 | 加密或损坏的文件请使用可读取副本；无文字 PDF 可在 House 配置 Docling OCR 后选择增强解析/整页 OCR 重试。 |
| 引用不能支持结论 | 回到原文核查，按内容质量问题记录。 |

反馈请提供应用版本、最短复现步骤、实际与预期结果。内容质量问题补充问题文本、允许使用的文献范围和预期证据页；不要发送密钥、完整数据库或私有论文。


## 能力边界

## 可选 AI 文献整理与专题建议

House → 文献解析与预览 → 导入后自动整理。默认关闭。开启开关即授权向当前聊天模型发送后续新导入文献的已解析文字，可能产生费用；请先保存可用聊天配置。现有文献不会批量补发。无需 Docling、LibreOffice 或向量服务，基础阅读不受影响。

文献资料 → AI 文献整理，可手动生成、重试、重新生成和停止，查看任务阶段与错误。每篇最多 32 个文字批次及一次汇总；超出预算明确报错，不偷偷截成首段总结。取消后丢弃未提交结果，但无法撤销已发送的模型请求；重启后不自动重发中断或失败任务。配置变化、资料并发修改或重解析导致本次结果不保存，请核对后重试。

AI 概述、研究问题、方法、对象/数据、结论、局限和标签与人工资料分开保存。查看依据可阅读原文内容块；结果未经人工事实校验，不能代替原件。可移除 AI 标签、隐藏结果；同一解析版本重新生成不会恢复已拒绝内容。重解析后旧整理标为过期，新结果成功前保留旧结果。人工总结和标签仍在编辑元数据页面维护，不会被生成覆盖。

最多推荐三个已有专题，展示共同主题词与原文依据。点击确认关联才建立关系；忽略会记住本解析版本的决定，已关联不重复推荐。不自动创建专题，也不因为推荐而扩大问答/草稿材料范围。

House → 检索 → 元数据辅助检索（试用），默认关闭。启用后标题、标签、人工总结及当前 AI 资料辅助查找，检索/问答/草稿仍引用原文。该方案仅通过固定自编写语料的工程评估，真实论文和真实模型质量待评估；无答案时仍可能误召回，请检查依据。

### 整理失败与资料页

文献资料页的标题、AI 整理、人工总结、标签和关联信息属于同一页面，整页统一滚动。整理失败不会删除已保存的人工资料或上一版 AI 结果。

失败时展开“失败详情”，可看到错误代码、阶段和相关字段。响应格式错误、字段类型错误和不合法来源编号会分别说明；不会保存模型原始响应或密钥。空值与文字列表等可安全转换的格式会直接规范化，不额外调用模型。对于活动决算等非研究材料，不要求编造研究方法或结论。若模型编造了来源编号，结果仍会拒绝保存；请核对聊天模型后手动重试。旧 INVALID_RESPONSE 记录没有字段细节，无法从旧记录还原具体原因。
