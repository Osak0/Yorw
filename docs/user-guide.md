# 知栖 Yorw 使用指南

适用：Windows x64 · 0.2.0 · 2026-10-26。

## 打开与配置

在完整分发目录中运行 `Yorw.exe`，或使用随包安装器。直接运行时需保留整个目录。程序已包含所需运行时；当前包未签名，尚未在独立干净 Windows 上验收。

退出旧版后再打开新版本。已有资料位于 House 显示的数据位置，升级会先备份数据库再应用迁移。0.2.0 的数据库版本高于 0.1.0，升级后的库需使用新版程序；自动迁移备份不是包含 PDF 等文件的完整工作区备份。

在 House 分别填写聊天模型与检索模型的地址、型号和密钥，保存后测试连接。密钥在应用中安全保存，不要发送到聊天或反馈中。数据默认保存在本地，云端模型会接收完成当前任务所需的相关文本。

House 的“语义检索”默认开启。关闭后，搜索和材料查找使用本地文字匹配；问答和草稿生成仍使用聊天模型。没有模型配置时仍能阅读、编辑和导出。

## Storage：阅读、搜索和问答

点击“导入 PDF”并选择文本 PDF。程序保存受管副本、按摘要去重并抽取文字；作者和年份等未知信息可留空。原始文件不会因为在知栖中移除文献而被删除。

点击“打开阅读”，可以翻页、缩放和返回已保存的物理页码。物理页包含封面等页面，可能与论文印刷页码不同。没有可提取文字的文件仍可阅读，但不提供 OCR 或图像分析。

**搜索：** 打开“检索”，输入关键词或问题，点击“搜索”。后台自动准备和复用索引，结果只查找当前文献。每条结果显示短原文摘录和页码；点击标题或“查看原文”跳到相应页。服务暂不可用时会展示可用的初步匹配结果。无匹配时可调整问法。

**问答：** 打开“问答”，输入问题并点击“发送”。后台查找原文、准备上下文并生成回答。可以接着问“它有什么限制？”等问题；近期对话用于理解指代，答案仍须寻找当前文献的原文依据。点击引用可查看原文，点击“保存到笔记”保存独立内容及引用。证据不足时不能把模型猜测当作论文结论。

**笔记：** 使用 Markdown 编辑，点击“保存笔记”或 Ctrl+S。切换文献时会话内的编辑保留，关闭前请保存；未保存编辑尚无崩溃恢复能力。

## Garden：描述要求，编辑草稿

创建或选择专题，在“AI 草稿”中描述要求并点击“生成草稿”。后台从整个工作区的已保存文献、笔记和其他 Wiki 查找相关材料，自动准备提示词。当前专题已保存正文用于提供背景；较长正文会自动选取相关背景，不要求先手动缩短。

生成中的内容会显示出来。完成后可以直接编辑草稿，展开预览或查看来源，然后选择：

- **追加到正文**：保留现有正文并添加草稿，自动整理新增引用编号。
- **替换正文**：用编辑后的草稿保存为当前专题的新修订。
- **忽略草稿**：保留生成记录，不修改正文。

生成不会自动覆盖正式正文。保存后的修订可以在“查看修订历史”中回退，回退会创建新修订并保留历史。

如果正文存在未保存修改，先保存或载入已保存版本，再处理草稿。正文或材料在生成后发生变化时，需要重新生成，避免覆盖新内容。笔记和 Wiki 的观点不会因为被模型引用就成为论文事实。

草稿因长度限制中断时会自动续写一次。仍未完成或连接中断时，已有内容保留，可在“草稿历史”中打开并补全；旧版有正文的失败记录也可编辑。原始生成记录和中断状态继续保留。

## House：内容导出

选择已保存笔记和 Wiki 当前修订，点击“创建快照并导出 ZIP”，通过系统对话框保存。取消后可以再次保存同一快照；修改正文后需要创建新快照。

ZIP 中的 Markdown 保持已保存正文原样，来源清单记录材料类型、原始证据、版本及导出时来源状态。追加和替换产生的来源关系同样会导出。

内容导出不包含 PDF、密钥、模型配置、完整对话、全部修订历史或未保存编辑，也不提供完整恢复导入。卸载程序配置为保留应用数据。

## 异常与反馈

| 现象 | 操作 |
| --- | --- |
| 模型未配置或鉴权失败 | 到 House 保存并测试相应模型配置。 |
| 搜索服务不可用 | 可先查看初步文字匹配；检查 House 配置后再试。 |
| 草稿未完成 | 编辑已有内容并核查来源，或调整要求后重新生成。 |
| 保存冲突 | 当前编辑保留，比较最新版本后再决定。 |
| 本地服务退出 | 关闭并重新打开；已保存内容和部分生成结果保留，中断任务不会自动重发。 |
| PDF 加密、无文字或损坏 | 使用可读取的文本副本，当前没有解密或 OCR。 |
| 引用不能支持结论 | 回到原文核查，按内容质量问题记录。 |

反馈请提供应用版本、最短复现步骤、实际与预期结果。内容质量问题补充问题文本、允许使用的文献范围和预期证据页；不要发送密钥、完整数据库或私有论文。


## 能力边界

| 范围 | 当前边界 |
| --- | --- |
| 分发 | Windows x64，本机验证；未签名，未在独立干净 Windows 验收。 |
| PDF | 每文件 50 MiB、2000 页；只抽取文字，无 OCR、解密、图像或复杂表格/公式理解。双栏和长文的抽取顺序仍需核对。 |
| 阅读 | 保存物理页码，不保存缩放或页内滚动；没有精确高亮、批注或 PDF 内搜索。 |
| 检索 | Storage 限当前文献，Garden 自动查找全工作区。语义及筛选效果取决于所配置服务，服务不可用或资料量过大时回退到初步文字匹配。结果摘要是原文切片。 |
| 模型 | 使用兼容 Chat Completions/embeddings 的服务，不保证所有厂商兼容。配置和密钥由用户提供。 |
| 来源 | 检查来源编号、范围和版本不等于验证模型解释。笔记、Wiki 观点与论文事实需要人工区分；原始图像证据不在当前能力范围。 |
| 对话 | 自动使用当前文献近期对话理解追问，保留最多四轮、约 6,000 字背景；不会使用其他文献的聊天记录。 |
| Garden | 自动选择最多 12 条相关材料，材料与证据有整体长度预算；较长当前正文自动选取背景。追加或替换保存为新修订，无段落级自动合并。新正文或来源变化后须重新生成。 |
| 生成恢复 | 长度截断自动续写一次；其他错误或重启中断不自动重发。部分内容可编辑补全。取消是尽力停止，不能保证服务商同步终止在途请求。 |
| 编辑 | 未保存的正文和草稿编辑仅在当前会话保留，无崩溃恢复。 |
| 导出与升级 | 内容 ZIP 不是完整备份，不包含 PDF、密钥、完整对话和修订历史，不提供恢复导入。数据库升级有内部备份；旧程序不能写新版数据库。 |
| 后置功能 | 无书目写作插件、完整 DOI/BibTeX 管理、联网抓取、云同步、多用户、图谱、时间线、Memory 或持续专题聊天。 |

真实模型逐题质量与独立干净 Windows 尚未在本轮整理中验证；旧版工程测试通过不代表这些评估通过。
