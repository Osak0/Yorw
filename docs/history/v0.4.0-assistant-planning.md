## Q1–Q33 讨论演进

已开始 grill-with-docs 多轮打磨；术语见 [GLOSSARY](../../GLOSSARY.md)。以下是讨论基线，不将尚未回答的建议写成确认决策。

### 第一轮：行为边界（2026-11-15 用户全部确认）

1. 首要验收：基于已导入的 Agent 论文和笔记连续讨论，整理问题、证据、候选 idea 和验证实验；记住用户确认／否定的内容，重开后继续，并可将选定成果采纳为专题笔记。大规模自动组织在该闭环后实现。
2. 原确认采用两个共享开关，已由第七轮 Q24 的统一笔记范围选择器替代；不再按旧开关开发。共享列表单独分组、默认收起，不自动全文发送。
3. 自动记忆区分明确表达与推断，后者标为未确认；保留依据，纠正优先，不将建议记为决定。
4. 正式资料修改统一预览采纳，包括明确创建指令；一次可确认整组。普通回答与自动记忆不需确认。见 [ADR-0001](../adr/0001-research-memory-and-adoption.md)。

### 第二轮：会话、共享与成果（2026-11-15）

- Q5 用户修订：左侧历史会话栏，由用户选择切换；入口默认开启新会话，不自动切换。新会话触发时点及会话内改范围规则已在第三轮确认，不采用上一轮“改变范围自动新建”的建议。
- Q6 已确认：共享入口编辑原笔记，显示归属；删所属专题须迁移或明确删除专题笔记，不静默级联；文献笔记保留。
- Q7 已确认：纠正优先；忘记阻止自动检索和总结重新召回，但保留历史供查阅，显式重新引入才恢复。删除记忆条目执行忘记。
- Q8 已确认：整理默认新增笔记，可选追加已有；明确重写才替换。多份成果分别标注标题／归属、独立选择采纳。

### 第三轮：会话生命周期与记忆边界（2026-11-15 用户全部确认）

- Q9：首页发送才创建会话；切回标签保留会话；新会话／历史由用户主动选择；重启首页不自动恢复最近会话。
- Q10：用户可在同一会话改范围，插入范围变更记录；后续材料重新校验，旧消息保留但不无条件注入。从专题进入不更改已有会话。
- Q11：全局记忆仅存偏好、通用约束与方向索引，具体研究状态归专题；专题范围不能通过全局记忆绕过隔离。未归属讨论留在会话。
- Q12：事件即时记录，总结闲时合并、前台优先；同范围 10 分钟最多一次，工作区每日默认 20 次，可配置／关闭，达限不阻塞问答。

### 第四轮：依据、采纳与撤回（2026-11-15 用户全部确认）

- Q13：笔记／记忆不能直接证明论文事实，核对当前原文，未核对标记待核实，旧编号不沿用。
- Q14：显示依赖，取消前置自动取消后续；独立成果分别采纳，选定集合事务校验，有冲突整组不写。
- Q15：后续编辑或新增依赖阻止整组撤回，展示冲突，另行提出修复方案。
- Q16：相关范围修改／用户记忆纠正／忘记停止旧任务，标记已有内容，失效未采纳方案，不自动发起新付费请求。

### 第五轮：调度边界与交付顺序（2026-11-15 用户全部确认）

- Q17：内容版本与摘要版本分离；自动压缩仅下轮生效，用户纠正／忘记／改范围使相关旧任务失效；后台提交校验内容版本。
- Q18：整个工作区单前台 AI 任务，其他请求保留输入不自动排队；后台空闲启动，不阻塞后来的前台。
- Q19：确认六阶段顺序，详见第 6 节；优先模型工具协议与只读助理，之后记忆、Garden、正式资料协作和综合验收。

### 第六轮：模型、事件归属与预算（2026-11-15 用户全部确认）

- Q20：DeepSeek 优先真实闭环；通用适配后逐家补 Kimi／GLM／Qwen，最迟阶段六记录可用账号的实测，未实测不宣称支持。
- Q21：文献阅读事件／问答只记一次，经关联检索，不复制成各专题结论；明确专题决定归当前专题，未归属决定留会话。
- Q22：单请求输入／输出 24000／4000，任务累计 80000／12000，可调整；达限保存结果后停止，用户决定继续。真实／估算用量分别标记。

### 第七轮：迁移、共享与忘记（2026-11-15）

- Q23 已确认：有草稿／生成历史也保留笔记入口，未采纳内容不升级成正文。
- Q24 用户修订：专题内统一笔记范围选择器，本专题／父专题／子专题分组展开勾选具体专题；展示与 AI 范围一致。替代第一轮 Q2 的开关模型，选择语义经第八、九轮锁定。
- Q25 已确认：按条目／消息／事件忘记，预览关联影响，默认工作区上下文生效；不屏蔽仍可用原文献中的概念，自然语言忘记先选候选。

### 第八轮：笔记范围选择合同（2026-11-15 用户基本同意并修订）

- 选择器使用实际专题名称，必要时显示层级路径；不得把示例名称 Agent 当成固定类别。
- 勾选专题默认包含其子专题，展开后逐项保留／舍弃；替代“单节点选择且不递归”的上一轮建议。
- 当前专题选择读取来源，不反向修改其他专题设置；来源按直接归属计算，不递归引用其他专题汇集的笔记。
- 选中来源包含其专题笔记及直接关联文献笔记，按 ID 去重；可追溯笔记引用原文，不因范围选择改写文献关系或关联材料列表。
- 父专题勾选带入兄弟分支、新节点及排除规则已由第九轮确认。

### 第九轮：范围树边界与后续变化（2026-11-15 用户全部确认）

- Q29：展示完整真实专题树，允许显式选择兄弟等其他分支；选中父专题默认包括其子树。
- Q30：新建子专题按最近祖先规则继承，明确排除的子树保持排除，手动重新选择才恢复。范围变化使相关旧任务失效，不自动重试。
- 此决策替代第一轮及早期计划中的“兄弟禁止共享／仅祖先后代”限制，见 [ADR-0002](../adr/0002-topic-note-scope.md)。

### 第十轮：恢复、记录管理与预算（2026-11-15 用户全部确认）

- Q31：移动后新祖先决定继承，节点显式规则保留；移动前预览影响，相关任务按范围变更停止。
- Q32：归档仍可参与记忆，删除会话排除其消息和派生记忆；已采纳笔记保留，说明删除影响，不承诺恢复。
- Q33：用户指引超预算可保存，但发任务前精简或提高预算；不静默截断，助理精简稿须用户确认。

### 一致性审查剩余决策（待确认）

- 来自共享来源的记忆是否随笔记范围变更一起失效。

后续沿已确认决策细化迁移、接口、阶段步骤及验收；未决问题不固化为架构。

## 最终范围补充（Q34、Q35，用户全部同意）

新专题默认本专题及子树，旧专题迁移保留本专题及后代，不自动引入祖先／兄弟。记忆保留来源依赖，来源出范围则派生记忆排除，混合条目无法拆分先整条排除再重建。用户独立重述可作新记录但不冒用旧依据。
