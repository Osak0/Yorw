## 实际实现

- **工作标签**：固定 Storage/Garden/House 导航下统一标签栏；页面以“类型:实体 ID”唯一，重复打开激活已有标签。模块首页不占用标签。标签支持关闭、关闭其他、横向滚动、键盘左右/Home/End、可见未保存标记和关闭前保存/放弃/取消。保存失败或冲突保持打开。
- **布局恢复**：主进程 `Layout` 读写 `userData/workspace-layout.json`，版本 1；校验标签类型、UUID、唯一键、激活项与模块一致、Storage/Garden 键归属、侧栏宽度和目录折叠，未知字段丢弃；临时文件加 rename，串行写入。恢复跳过不存在的文献/专题并提示，损坏布局回退 Storage 首页。布局不含正文、密钥、聊天输入或任务结果。
- **按实体状态**：`session-state.ts` 按文献保存页码、缩放、侧栏模式/宽度、搜索输入、问答输入；按专题保存 AI 生成要求。笔记和 Wiki 草稿继续由 `Notebook`/`GardenBook` 按实体保存。工具侧栏和标签共享同一份状态，任一时刻只挂载一个宿主。
- **Storage**：阅读标签保留工具栏、页码、缩放和工具入口；笔记/检索/问答可侧栏或独立标签；工具标签的引用跳转激活正确文献的阅读标签并定位物理页；关闭阅读标签后可从来源重新创建；阅读标签去重。
- **问答**：上方可滚动消息列表，下方固定输入区；问题气泡与自然展开的回答区分；引用、来源、重新回答和保存笔记在回答下方；生成时跟随底部，向上阅读显示“回到最新”；Enter 发送、Shift+Enter 换行、组合输入不发送；停止、失败和重试保留已有内容；切换标签不自动重发。
- **Garden**：目录可收起并在布局中保存；新建使用紧凑入口；专题正文为默认标签，包含标题/父级路径、折叠的名称与父级、编辑/预览/保存/AI 优化/修订历史；AI 优化和修订历史分别是所属专题标签。AI 优化复用原选材、草稿截断恢复、来源检查和追加/替换；历史标签复用 revision 比较和回退。正文有未保存修改时 AI 采纳和回退受原有冲突规则保护。
- **尺寸**：固定顶部导航与标签栏，PDF、侧栏、聊天、Garden 目录/内容各自滚动；显式卡片样式替代宽泛全局 `section`；窄窗口保留 1100px 侧栏覆盖面板和关闭后的焦点返回。

## 失败与修复记录

- **报告目录相对路径**：首轮 Electron 烟测按 `apps/desktop` 解析相对 `--report-dir`，找不到 `fixture.pdf`（ENOENT）。改用绝对报告目录后通过；未改产品路径。
- **退出竞态**：烟测退出时 renderer 仍轮询 `app:getStatus`，窗口销毁后访问 `webContents` 记录 `Object has been destroyed`。增加 `window.isDestroyed()` 守卫；不影响业务。
- **服务端渲染测试**：`useSyncExternalStore` 缺少 `getServerSnapshot`，现有静态 Markdown 面板测试失败。补充同一快照函数后 41 项通过。
- **聊天流式夹具**：本地测试服务器在请求体结束时清除定时发送器，导致回答超时。改为在响应关闭时清理；60 个增量分块正常流式。该问题只在测试夹具，不在产品。
- **AI 烟测目录刷新**：烟测通过后端直接创建“Prior”专题后，隐藏的 Garden 目录仍是启动时列表，按 `data-topic-id` 找不到。烟测在切换前点击“刷新”；产品内通过 GardenBook 创建的专题会正常更新。
- **布局烟测辅助函数**：目录收起检查调用了 `ui` 未定义的 `button`；补齐后通过。工具返回侧栏一度使用等待式检查，改为点击后 500ms 记录 `sidebar/chat/reader` 状态并断言，避免瞬时等待误判。
- **工具宿主证明时机**：notes 的 `returned` 在切到问答后才检查，记录为 false；改为在返回当时捕获。产品行为已由等待条件证明。
- **打包烟测的服务退出定位**：AI 故障烟测仍查找 `main` 内的“本地服务已退出”，而阶段 A 的状态条已移到 main 外的 `.app-status`。改为检查 `.app-status.failed` 或 body 文本后，打包完整流程与恢复通过。
- **回到最新按钮不可读（用户 review）**：`.chat-latest` 的类选择器被 `.chat-panel button` 的颜色/边框规则覆盖，按钮呈蓝底蓝字。改为 `.chat-panel .chat-latest` 高优先级的白字胶囊，增加向下箭头和“跳转到最新消息（对话底部）”提示；聊天烟测增加按钮文本及前景/背景对比断言。
- 以上失败均未通过放松业务断言、删除测试或伪造记录解决。

## 已知限制

- 阶段 A 仅在工作分支；**未合并 main、未发布、未构建 NSIS 安装器**。打包目录是本机受限 PATH 检查，不等于独立干净 Windows；夹具不证明真实模型质量。
- 布局恢复只含标签/激活项/模块首页/侧栏模式与宽度/目录收起；搜索与问答输入、页面缩放、未保存正文、AI 草稿编辑和任务结果只在当前会话。无崩溃恢复。
- 目录收起状态由 App 布局保存/恢复并有布局合同测试和界面收起检查；本阶段没有单独做“收起后重启仍收起”的整机复现。
- AI 优化仍使用全工作区材料；专题及子专题范围筛选属于步骤 11，未提前实现。文献元数据、资料集合和文献/专题关系属于步骤 7–10，未实现。
- Storage 工具标签当前覆盖笔记/检索/问答；Garden 辅助标签覆盖 AI 优化/修订历史。没有多会话聊天、段落级合并或新的检索算法。
- 真实云模型逐题质量、跨语言召回、服务商兼容性和干净 Windows 安装/恢复仍需在用户 review 与后续阶段单独验证。
