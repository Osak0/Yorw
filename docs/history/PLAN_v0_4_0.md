## 已确认的产品行为

### 文献管理入口

文献卡片标题下仅保留“打开阅读”和“管理文献”。管理按钮去掉箭头角标，以颜色区分展开状态；保留焦点反馈、键盘操作与 aria-expanded。

点击管理后，在其下方依次排列六个按钮：**编辑元数据 → 笔记 → 检索 → 问答 → 解析 → 删除文献**。前四项各开对应工作标签，同一文献同一模块只保留一个标签；解析按钮在下方展开处理器选择、重新解析及停止等操作。删除沿用确认和未保存内容保护。

原“文献资料”和“整理文献”的职责重新分配到以上模块，不再保留两个重复聚合页面。阅读工具栏原“资料”改为“编辑元数据”；笔记、检索、问答快捷操作继续可用。

### 元数据与 AI 辅助

元数据顺序固定为：标题、作者、年份、关键词／标签、总结、相关文献、所属专题。关联材料与专题归入元数据编辑页面。

元数据上方设置“AI 辅助文献整理”按钮，打开独立工作标签：已有结果直接展示，运行中任务复用；无结果且无运行任务时启动生成；失败或取消后显式重试，不因进入标签循环调用。结果页提供重新生成及生成历史。

AI 按七类元数据提供建议。事实字段依据当前原文，未知作者、年份等允许留空；相关文献和专题仅从已有本地库推荐，无匹配留空，不联网找文献、不自动创建专题。关联建议附理由，与原文事实区分。

按最新 review 要求取消勾选框，每栏直接提供添加、替换按钮；添加该栏建议，替换前确认当前与建议值。标题、年份支持填空或替换；作者、标签、总结、相关文献、所属专题支持追加或替换。列表追加去重；关系替换明确显示将解除的关联。生成不自动改变正式元数据。

### 检索与问答

“检索历史”“问答记录”入口分别命名为“检索”“问答”，在对应操作页内部管理历史。

- 检索页包含输入、结果和可收缩历史侧栏；选择历史只恢复查询及结果快照，显式重新检索才请求模型。
- 问答页顶部直接显示搜索框，搜索当前文献全部已保存问题和回答，显示摘要，点击定位并高亮原记录；保持连续问答，不新增会话分组。
- 按最新 review：仅独立检索标签用左侧可收起历史栏，阅读侧栏不显示检索历史；两种视图共享当前查询与最新任务结果，历史快照只在独立标签显示。定位旧消息后暂停自动滚动到底部，提供“回到最新”。

## 阶段一：PDF 阅读与检索降级体验

**状态：osako review 通过，已提交 978f865。目标：** 修复适合宽度下反复加载与晃动，并解释和改善语义检索降级。

**输入／输出：** 输入为现有 PdfReader、尺寸样式、检索任务与返回原因；输出为稳定阅读行为、明确降级原因和恢复入口。

1. 用自编写横版发票、纵版、多页 PDF 复现，检查滚动条、ResizeObserver、画布尺寸与渲染取消的反馈循环。当前代码的尺寸反馈是待验证假设，不能先写为已确认根因。
2. 稳定滚动区域宽度，按真实内边距计算可用宽度；仅有效渲染尺寸变化时重绘，固定缩放不因无关容器宽度变化重绘。旧任务不能覆盖新任务状态，加载状态最终结束。
3. 只读检查对应任务 reason、索引与配置完整性，定位截图中实际降级原因，不读取或展示密钥，不主动发送用户文献。
4. 分别解释配置／密钥缺失、索引未就绪、配置／原文变化和服务失败，保留关键词结果，提供设置或显式重试入口；未知错误显示安全错误码。

**接口影响：** 复用检索结果 mode/reason；补齐前端原因映射及设置导航。确需增加原因时同步 Python 返回、共享类型与受限 IPC，不暴露凭证。

**验收／review：** 适合宽度稳定；侧栏开关、调整窗口、翻页、缩放后不循环加载；关键词模式不误报故障。验证各降级原因及恢复路径。若无法从安全诊断确定截图原因，如实记录未确定及后续核查步骤。

## 阶段二：统一入口与工作标签

**状态：osako review 通过。目标：** 六个管理按钮和模块职责统一，去除重复资料页面。

**输入／输出：** 输入为文献列表、资料／元数据组件、标签和布局合同；输出为统一菜单、元数据编辑页及兼容标签恢复。

1. 实现六个入口及解析二级展开，避免展开时管理按钮跳位。
2. 元数据按七字段顺序排列，关系和专题纳入页面，继续使用现有关系存储；AI 入口在阶段三接通。
3. 原资料中的笔记、检索、问答内容迁入对应标签，历史生成结果迁入阶段三 AI 标签；阅读工具栏、目录右键等入口同步。
4. 更新标签去重、主进程布局校验、恢复及草稿保护。旧 metadata 恢复为编辑元数据，旧 resource 映射到编辑元数据并去重，旧生成记录保留可访问。

**接口影响：** 同步 StorageTool、工作标签、布局读写白名单和 renderer 分发；沿用文献、关系及专题业务接口，不因入口调整复制业务状态。

**验收／review：** 文献卡片仅两个主入口，六按钮顺序正确；重复点击激活已有标签；切换保留草稿，关闭有保护，重启恢复；删除文献后关联标签正确关闭。

## 阶段三：AI 辅助文献整理

**状态：已实现，等待 osako review。目标：** 独立 AI 结果页、七类建议与逐字段原子采纳。

**输入／输出：** 输入为当前解析原文、元数据和本地候选；输出为可追溯生成记录、字段差异及经确认保存的正式元数据。

1. 接通“AI 辅助文献整理”标签及已确认的生成／复用规则，保留历史、隐藏／恢复和来源跳转。
2. 扩展结果覆盖七类字段；本地筛选有限候选，再由模型依据候选摘要与当前文献给出关联建议和理由；只接受候选集中的实体 ID。
3. 提供字段勾选、加入／替换、差异预览和统一提交。元数据有未保存草稿时，先保存或放弃再采纳。
4. 扩展采纳接口为逐字段操作与关系变更，在单个事务内校验文献／原文版本、关系快照及候选有效性，提交正式字段与采纳审计。
5. 并发变化或候选删除时整次拒绝并保留选择；失败不留下部分更新。旧结果缺少新增字段按“无建议”展示，过期原文结果只读。

**接口影响：** 扩展 Enrichment 结果、采纳 DTO、共享类型和固定 IPC；新增作者追加、关联建议及关系采纳。需要新增持久化字段时追加 024 及后续迁移，旧迁移不改写；保持 SQLite 权威存储和现有来源追踪。

**验收／review：** 七类建议可独立选择；预览与实际写入一致；重复点击不重复创建任务；追加去重、替换、取消、非法候选、原文过期、并发冲突与事务回滚均验证；模型夹具不代表真实生成质量。

## 阶段四：历史整合与完整回归

**状态：未开始。目标：** 检索／问答操作与历史同页，完成跨视图和持久化回归。

**输入／输出：** 输入为已保存检索快照、问答记录与共享会话状态；输出为可浏览检索历史、可搜索定位问答的统一页面。

1. 检索页实现可收缩历史侧栏（阅读侧栏取消历史）、快照恢复、单条删除、清空与过期来源提示；重新检索显式执行。
2. 问答页实现当前文献问题／回答正文搜索、匹配摘要、定位高亮及回到最新，不引入会话分组。
3. 独立标签和阅读侧栏保持查询、结果及历史选择一致；必要时扩展后端查询及受限 IPC，搜索记录不调用模型、不跨文献。
4. 运行类型检查、相关前后端测试、构建及隔离工作区窗口验证；涉及冻结服务先重建后端。覆盖 1024／1280／1440 宽度、侧栏切换、连续操作、重启和旧库升级。
5. 同步当前使用、架构及开发说明，实际过程与报告指针归入 history；保留失败事实与验证边界。

**接口影响：** 复用检索历史快照，扩展问答查询／定位能力及共享会话状态；新增接口同步两端合同与授权校验。

**验收／review：** 查历史不发模型请求，重新执行明确；搜索覆盖当前文献全部已保存问答，可定位原记录；两种宿主不丢草稿与状态；重启恢复和来源跳转正确，最终门禁及文档一致。
