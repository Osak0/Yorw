## 最终实现与关键决定

- SQLite 继续作为正文和来源权威存储。016 增加版本化内容块，017 处理器设置，018 OCR 引擎，019 可重建预览及定位缓存；旧 PDF chunk 引用保持兼容。已应用迁移不改写。
- 解析尝试与活动正文版本分离；中断后可重试，失败保留上一可用正文/索引，取消或过期回调不能激活结果。任务捕获配置快照；导入/重解析排队不在数据库锁内执行慢速组件探测。
- PDF/DOCX/MD/TXT 默认内置处理，旧增强优先设置不影响新导入。DOCX 直接从受管 OOXML 读取只读展示树，保留正文、基本样式、表格和常见栅格图片；不从检索块拼接全文。DTD、外部关系、SVG 和任意 HTML 被阻止，解压体积、节点、文字和图片有上限。
- 旧 DOC 的完整处理需要可选 LibreOffice；DOCX 不需要它。LibreOffice 的 Word 版式预览由用户主动点击；Docling 只在显式增强重解析/OCR 中使用，不安装到 Yorw 环境或安装包。
- main 原生选择并确认程序，记录组件指纹，启动只恢复未变化的授权；禁止任意启动参数。普通状态查询不执行程序，显式检测与实际处理才执行。LibreOffice 配置在检测、解析和转换中共享；Heading 7–9 保留章节关系，展示降为六级。
- 首轮通用“原件加载失败”的一个具体原因是 main 错误码白名单遗漏 COMPONENT_APPROVAL_REQUIRED；现已抽取公开错误码处理并补充测试，保留可操作错误，屏蔽私有信息。
- 引用统一为“查看依据”：先显示摘录及章节，唯一匹配时辅助标记原件/转换页；无预览时不留无反馈跳转。转换映射带预览和内容版本，处理跨页、重复页边文字及基础表格；歧义明确不匹配，转换页号不写回来源快照。
- House 首页保留四个入口，设置标签去重/恢复、切换保留草稿、关闭有修改时确认；密钥草稿只在内存。笔记、检索、问答、专题及历史来源共用阅读入口。
- 主界面 RAG 消费活动内容块，来源携带 block_id/section_path，PDF 保留物理页。旧 search/chat API 仍保留 PDF chunk 兼容路径；后续改动须区分现役统一 workflow 与兼容入口。
- 内容导出增加格式和定位，仍不是完整备份。未实施自动总结、AI 标签、专题推荐或新的检索排序；这些属于阶段二。
