#### 实现与复现

- Electron 管理 Python 子进程，经 stdin 传递随机会话令牌，后端只绑定 127.0.0.1 随机端口；通过健康检查后报告 ready。启动失败显示错误码，异常退出显示失败状态。
- renderer 开启 sandbox/contextIsolation、关闭 Node，只经受限 preload 获取状态；IPC 校验主窗口、主 frame 与页面 URL，拒绝外部导航、新窗口和权限请求。生产包不读取开发页面地址环境变量。
- stdin shutdown/EOF 控制后端退出，超时只终止本次子进程并等待退出；关闭发生在启动前时不再创建后端。
- Storage/Garden/House 为可切换的最小导航壳，显示真实服务状态。没有文献、数据库持久化、模型或 Wiki 业务。

#### 实现与设计取舍

Electron main 将 `userData/workspace` 经启动配置交给 Python；renderer 不获得任意路径访问。开发目录仍为独立 Yorw-development，正式程序使用自己的 userData。工作区创建 documents、tmp、logs、backups 及 yorw.sqlite3，放在安装目录之外。

SQLite 仅创建 schema_migrations 和 workspace_meta（稳定 UUID 与创建时间），不提前创建未来业务表。连接启用外键、WAL、busy_timeout；服务内写入通过同一 RLock 与显式事务串行执行。健康检查返回真实 schema_version=1；受鉴权的 GET /v1/workspace 返回身份、创建时间与版本，不返回路径。

迁移使用有序 SQL 与 SHA-256 校验；拒绝较新数据库、历史缺失和已应用脚本变化。已有版本升级前使用 SQLite backup API 生成内部备份，备份失败停止；每步迁移在事务内写入结构、历史和 user_version，并验证完整性及外键，失败回滚。没有执行失败后自动覆盖/恢复用户数据库。SQL 作为 PyInstaller 数据资源打包。

受管理文件先独占创建 UUID 临时文件，完整写入和 fsync 后以不覆盖方式发布；只接受规范 UUID，路径不得跳出受管目录或跟随文件/子目录重定向。操作失败只清理本次创建的暂存文件；未知临时文件和已有文件在重启时保留，避免推测删除。当前这是存储原语，不是 PDF 导入 API，也不判断 PDF 合法性。后续步骤 5 负责摘要去重、业务事务及孤立导入对账。

生成基于聊天服务，SSE 内容增量本地保存；同一专题一次一个生成任务，有限单 worker 排队。输入/输出快照、服务配置、提示版本、基础正文、当时标题和状态均持久化；request_id 幂等，同一请求重发返回原草稿，不重复调用模型。成功后重新预览会生成新的请求标识，明确确认后才再次生成。取消保留部分输出，在途请求可能仍计费；网络阻塞沿用 20 秒 socket 超时、180 秒流时长/大小限制，失败不自动重试。启动时将 running 标记为 interrupted，不自动重发收费请求。

建议草稿独立存储，**生成、取消和失败均不修改 topics 当前指针或 revisions，也不覆盖当前编辑器草稿**。专题正文后来保存新修订时，旧建议标为基于旧正文；本步不提供采纳、拒绝、覆盖正文或回退，留给 Step 12 的比较确认流程。

#### 功能与边界

采纳必须满足：建议已完成且未处理；请求基线与当前正文相同，且也是生成时基线；原材料版本及证据仍有效；正文非空且不超过 200,000 字，至少含一个合法的本轮 [S编号] 且没有越界引用。旧基线必须重新生成，不能借“已比较”绕过服务端冲突检查。对正文和引用语义的正确性仍由人工判断，不以编号合法代替事实验证。

| 每份 .md 对应 .sources.json / .sources.md | 对象元数据、原始来源/材料及证据快照、导出时可用性；来源编号仅在本份正文内有效 |

UUID 文件名避免标题中的路径字符、同名与 Windows 保留名问题；标题在 manifest 与来源清单保留。正文中的 [S编号] 不改写，来源种类仍区分原文、笔记与模型讨论；来源存在不代表事实已被证实。来源清单可能包含未在最终正文使用、但确实提供过的上下文材料，不能全视为正文已引用。

**内容导出不是完整工作区备份**：不含 PDF、密钥、模型配置、聊天历史、未采纳建议、未保存草稿或完整修订历史，不具备恢复导入/迁移能力。来源摘录可能包含用户选择的研究内容，导出前应核对选择。

#### 写入与失败规则

GET /v1/workspace 不接受任意路径；main 补充自己当前实际配置的位置。GET /v1/exports/catalog 返回笔记和专题列表；POST /v1/exports 接收 IDs，在 workspace/tmp 写出独立 export-{task_id}.zip，登记 tasks(kind=export, stage=EXPORT_READY)；GET /v1/exports/{task_id}/file 仅返回对应已成功任务的受限文件。

renderer 只提交选择和任务 ID，不接收通用文件路径写接口。main 打开系统保存对话框，解析所选目标父目录的真实位置，拒绝工作区及应用数据目录内的目标，避免覆盖数据库/受管资料/密钥；同目录独占临时文件写完后 rename 发布。取消、超限、路径受保护、下载或写入失败均不报告成功。成功覆盖已有目标由系统对话框明确提示。

取消保存后可以“再次保存这份快照”，内容保持创建时版本；修改选择或正文后需重新创建快照。临时 ZIP 存在当前工作区 tmp，重启后服务端任务及文件仍可读取；House 最近快照按钮为本次会话状态，重启后可重新创建，不承诺导出历史管理或自动备份。
