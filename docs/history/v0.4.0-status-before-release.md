## R2 交付（整改）

- 纠错与执行：每用户请求最多两次可修正反馈，第三次 `CORRECTION_LIMIT_EXCEEDED`；重复相同调用 `REPEATED_TOOL_CALL`。所有尝试计入 8 轮、16 次工具、180 秒与 token 预算；多工具顺序执行并分别记录，成功结果不因同轮其他调用失败而丢弃；停止、范围／记忆变化、来源失效仍终止。
- 持久化：迁移 030 新增 `research_tool_calls`，保存调用 ID、工具、状态、输入摘要、结果摘要、错误、可修正标志、对象／方案引用和时间；与 `sources_json` 同一写事务更新。会话读取返回 `tool_calls`，旧任务缺记录时为空，不伪造。实时事件只保留名称、调用 ID、状态、错误与可修正标志；不保存隐藏思考、密钥或完整笔记正文。
