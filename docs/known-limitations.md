# MVP 已知限制

0.1.0 本机验证版 · 2026-10-25。使用方法见[使用指南](user-guide.md)，完整开发状态与验证证据随仓库中的 PLAN.md 和步骤验收记录维护。

| 范围 | 本版边界 |
| --- | --- |
| 分发环境 | Windows x64 优先；未签名。已选择先做本机验证，没有干净 Windows/其他设备的验证结论。 |
| PDF | 每文件 50 MiB、2000 页；只抽取文字，无 OCR、解密、复杂表格/公式或图像理解。长文/双栏与中英文的真实抽取质量仍需人工核对。 |
| 阅读 | 保存物理页码，不保存缩放/页内滚动；没有精确引用高亮、PDF 批注或 PDF 内搜索。 |
| 检索 | 只限当前文献；关键词不提供可靠跨语言匹配。语义效果取决于实际服务和材料，默认阈值未普遍校准。每篇最多 5000 个语义分块。 |
| 模型 | 使用兼容 Chat Completions/embeddings 的服务，不能保证所有厂商兼容；云端需网络、用户密钥且可能计费。历史接入 review 不代表所有论文/问题效果已通过。 |
| 引用 | 校验来源 ID、范围和版本，不证明模型语义解释正确。笔记观点、AI 推断与论文事实需人工区分；图像证据不在能力范围。 |
| 编辑与恢复 | 已保存正文、历史和来源持久化；未保存草稿仅本次会话保留，没有崩溃恢复。服务退出后需重新打开应用。 |
| Garden | 建议使用完整替换正文的显式确认；没有段落级自动合并。旧基线须重新生成。每次最多 8 个材料对象，单项 8,000 字、材料合计 24,000 字、已保存上下文正文 20,000 字。 |
| 生成 | 输出上限与服务截断可能导致失败；中断任务不自动重新收费请求。取消是尽力停止，不能保证服务商停止计费。 |
| 导出 | 已保存笔记和 Wiki 当前修订；一次最多 500 项、正文与清单合计及 ZIP 本身上限 20 MiB。不含完整备份/恢复、PDF、密钥、完整聊天或修订历史。 |
| 后置功能 | 没有书目写作插件、DOI/BibTeX 完整管理、联网抓取、云同步、多用户、图谱、时间线、Memory、个人资料或持续主题聊天。 |

自动化中的 PDF 与本地假模型只验证工程流程和异常行为，不能作为真实科研资料或模型质量的准确率证据。真实代表性论文及固定问题的逐题评估，留待本轮深度体验记录。
