# Yorw v0.4.0

本版围绕连续研究工作流，将文献阅读、研究会话、可纠正记忆、专题笔记与人工采纳的修改方案连接起来。

## 主要更新

- Garden 研究助理支持本地检索、按页读取原文、浏览 Storage 目录和 Garden 专题；完成回答后提供经服务器校验的资料入口。
- 多模型配置与独立聊天／工具能力检测；工具参数可反馈纠正，执行受范围、轮数、时间和用量限制，工具记录与会话可恢复读取。
- 研究会话支持重命名、分区、归档与删除；纠正、忘记、恢复和研究指引形成可控的研究记忆，Research.md／Log.md 仅为导出。
- 专题与笔记分离，专题管理多份笔记、材料和普通关联；笔记范围按显式选择和最近祖先计算，不因普通关联扩散。
- 专题、笔记和关系修改先生成方案，在独立详情标签选择采纳；支持部分采纳、版本冲突保护、幂等及受保护的整组撤回。
- PDF 证据定位、连续问答历史、文献整理与成果导航改进；统一多行输入与 Storage／Garden／House 界面布局。

## 安装与升级

安装器名称为 `Yorw-Setup-0.4.0-x64.exe`，配套 `SHA256SUMS.txt` 用于核对下载内容。完整目录运行需保留全部文件。包含 Electron 与冻结 Python 后端，基础功能不要求另装 Node／Python；未签名，无自动更新。

应用／后端版本 0.4.0，SQLite schema 31。旧库顺序升级，迁移前创建数据库备份；升级前退出旧程序并另行备份完整工作区。内容导出 ZIP 不包含完整原件工作区，不能替代备份。不要用旧版直接打开已升级数据。

PDF、DOCX、Markdown、TXT 基础能力内置；旧 DOC、增强解析与 OCR 的可选组件由用户自行安装。模型服务在 House 配置，调用会发送所选材料至所配服务。
