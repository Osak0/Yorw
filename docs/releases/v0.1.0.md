## 知栖 Yorw：自己的科研工作区

首版面向 Windows x64，连接文献阅读、带来源问答、笔记与专题 Wiki。

- **Storage**：PDF 导入与去重、元数据编辑、阅读与物理页恢复、Markdown 笔记、文献内关键词/语义检索、带来源问答及回答转笔记。
- **Garden**：专题目录和手工修订；从论文片段、笔记、对话选材生成独立建议，比较后采纳或拒绝，保留来源并支持历史回退。
- **House**：聊天和 embedding 独立配置与安全密钥保存；查看工作区位置，导出已保存笔记和 Wiki 的 Markdown 与来源清单。

本版还修复了慢 PDF 客户端可能阻塞服务退出的问题。内容默认本地保存，云端服务调用会发送用户确认的相关文本并可能计费。

## 安装与附件

从发布页下载 `Yorw-Setup-0.1.0-x64.exe` 安装；直接运行本机分发目录时需保留完整目录。

当前发布附件包括安装器、`Yorw-MVP-samples.zip`、`SHA256SUMS.txt`、`user-guide.md` 和 `known-limitations.md`；`artifact-manifest.json` 仅保留在本机验证制品中；使用说明见[使用指南](../user-guide.md)。本地制品位于 `release/step14-review/`。样例为自编写测试资料，不是真实科研结论。

## 验证与限制

本机后端 94 项、桌面 25 项测试通过；实测安装、连续流程、服务中断与重启、来源/正文恢复、导出和卸载。本机受限 PATH 验证通过，但未在独立干净 Windows 环境验收。

当前包未签名。没有 OCR、复杂表格/图像理解、精确引用高亮或未保存草稿崩溃恢复；引用存在不保证回答正确。内容导出不是完整备份，不包含 PDF、密钥、完整聊天或修订历史，也不支持恢复导入。完整边界见[已知限制](../user-guide.md#能力边界)。

真实代表性论文、跨语言召回与回答质量仍需逐题核查，不用本地假模型结果宣称准确率。[反馈模板](../development.md#如何解读结果)用于记录下一版改进。
