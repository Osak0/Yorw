# Yorw v0.3.0

本版将文献导入、原件阅读、带来源问答、笔记与专题正文连接为本地科研工作区。

## 主要更新

- PDF、DOCX、Markdown、TXT 内置导入和处理；旧 DOC 经可选 LibreOffice 转换。DOCX 基础原件预览无需外部组件。
- 统一解析合同与第三方适配，支持主动选择 Docling 增强解析和 OCR。
- AI 文献整理支持生成历史管理、隐藏与恢复、元数据建议及显式采纳；标签和总结使用统一正式元数据。
- 保留 SQLite FTS5/BM25、向量检索和 RRF，增加可选元数据辅助检索。
- 文献逻辑文件夹、右键操作、目录宽度调整及独立资料/元数据标签。
- Garden 层级与路径视图、搜索、新建和管理标签、正文侧栏；专题右键菜单支持单专题删除，直接子专题提升，文献与修订保留。
- House 设置入口与标签页、草稿保护、来源与修订版本检查。

## 安装与数据

使用 Yorw-Setup-0.3.0-x64.exe 安装，校验同目录 SHA256SUMS.txt。安装包包含桌面程序和冻结 Python 后端；基础功能不要求另装 Node 或 Python。模型配置在 House 填写。

数据库升级至 schema 23，迁移前自动保存数据库备份。卸载保留应用数据。导出 ZIP 包含已保存笔记、专题正文和来源清单。
