# Yorw v0.2.0：本机 review 版

2026-10-26 · 等待用户 review，尚未合并或公开发布。

本轮只处理草稿生成失败、AI 交互繁琐和检索体验三个问题。

- 搜索输入问题后直接运行，默认语义检索，索引在后台准备并复用。结果显示短原文摘录和跳页入口。
- 文献问答直接发送，后台查找证据；支持当前文献的连续追问。
- Garden 描述生成要求后自动从全工作区的文献、笔记和 Wiki 选材。生成内容可编辑，选择追加或替换，保留来源与修订。
- 草稿输出预算独立配置；长度截断自动续写一次。未完成内容和旧版失败记录可编辑补全。
- House 可关闭语义检索。工作区升级会先进行数据库备份；旧程序不能写入新版数据库。

打开完整分发目录中的 Yorw.exe，或使用本轮本机安装器。分发包未签名，没有自动更新；未在独立干净 Windows 上验收。v0.1.0 的发布附件保持原样。

完整流程使用自编写 PDF 和本地模型夹具验证。用户已选择在最终 review 程序的 House 中配置真实服务，再核查检索和生成质量；此处不提供真实模型准确率结论。
