# Yorw v0.2.0

2026-10-27 · Windows x64 · schema 15 · **发布准备稿，尚未发布**。

用户确认此前 v0.2.0 未发布；本版合并原 AI 流程改进与原定 v0.2.1 的阶段 A/B/C，统一以 v0.2.0 交付，不单独发布 v0.2.1。阶段 A/B 已合并，阶段 C 已通过用户 review，当前仍待仓库整理审查、提交及合并；本次不创建 GitHub Release。

## 工作区与阅读

- 固定 Storage / Garden / House 导航和统一工作标签；标签去重并恢复布局。文献笔记、检索、问答可在阅读侧栏与独立标签间切换。
- 问答上方显示记录，底部固定输入；支持连续追问、停止、查看来源和保存为笔记。
- Garden 正文、AI 优化、修订历史与关联材料分开，专题目录可收起，正文保留完整编辑空间。

## 文献与知识关系

- 多选导入 PDF，逐文件显示成功、重复和失败；可跳过整理直接阅读，或在独立标签编辑元数据。
- 文献目录可收起，首页支持本地搜索；文献资料聚合标签、人工总结、专题、相关文献、笔记及检索/问答历史。
- 支持双向相关文献和文献—专题多对多关系；专题汇集子专题材料，文献笔记随关系展示，不复制正文。

## AI 检索与草稿

- 输入问题即可搜索或问答，后台准备索引和证据；搜索显示短原文摘录与物理页跳转。语义检索默认开启，可在 House 关闭。
- AI 优化默认从当前专题及子专题选材，显式切换才使用全工作区；空范围不自动扩大，材料、范围或版本变化时保护已有草稿并检查采纳条件。
- 草稿可编辑后追加或替换 Wiki，保留修订与回退；长度截断自动续写一次，未完成内容可继续编辑。

## 升级与能力边界

退出旧版后升级。数据库迁移至 schema 15 前自动创建数据库备份，旧程序不能写新版数据库；该备份不包含完整 PDF 工作区。

- 安装包未签名，无自动更新；独立干净 Windows 安装/恢复尚未验收。
- 真实模型逐题质量与服务商兼容性尚未完成独立评估；本机夹具结果只证明工程流程。
- PDF 仅文字抽取，无 OCR 或图像/复杂表格理解；总结当前为手工编辑，不自动调用总结 API。
- 笔记、Wiki 与 AI 草稿有未保存保护；整理文献表单仅在当前会话保留，关闭标签或退出会丢弃，请先保存。
- 内容 ZIP 不含 PDF、完整对话/修订、标签/总结、关系或检索历史，不提供完整工作区恢复。
